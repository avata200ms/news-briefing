🔑 API 키 설정 가이드

본 서비스는 실시간 뉴스 검색 및 AI 선별/요약을 위해 두 가지 무료 API를 사용합니다.

1. Naver Search API (네이버 뉴스 검색)

• 발급처: 네이버 개발자 센터

• 애플리케이션 등록 시 '검색' 서비스 선택

• 발급받은 Client ID와 Client Secret을 .env 파일에 입력

2. Google Gemini API (AI 선별 및 3줄 요약)

• 발급처: Google AI Studio

• 무료 API Key 생성 후 .env 파일의 GEMINI_API_KEY에 입력

# 프로젝트 루트 디렉토리의 .env 파일에 작성
NAVER_CLIENT_ID=your_naver_id
NAVER_CLIENT_SECRET=your_naver_secret
GEMINI_API_KEY=AIzaSy...
GEMINI_MODEL=gemini-3.6-flash
